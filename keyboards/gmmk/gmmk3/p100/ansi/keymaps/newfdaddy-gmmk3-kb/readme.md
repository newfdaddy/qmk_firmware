# GMMK V3 100% ANSI Layout
# Chris Jones

# Description
Keymap made for myself.

# Options and changes 
* Disable mouse key function
* Enable tap dance
* Enable dynamic macros
* Remove tons of animations and matrix effects leaving essentially backlighting
* Turns off lighting when USB sleeps
* Turns off lighting after 10 minutes of inactivity

# Lighting changes
* Lights the Caps Lock / Num Lock keys red when active
* Lights the ESC/~` keys red during layer 1 active
* Lights FN key red during layer 1 active
* Lights the media and macro keys green when layer 1 active

# Keymap changes
## Layer Changing
* FN is momentary Layer 1
* Double Tap Right Shift to Enable/Disable Layer 1
## Base Layer Changes
* No changes from default
## Layer 1 Changes
* Esc - Enter Bootloader
* `~ - Reboot KB
* KP4 - Dynamic Macro 1 Record/Stop Recording
* KP5 - Dynamic Macro 2 Record/Stop Recording
* KP1 - Dynamic Macro 1 Activate
* KP2 - Dynamic Macro 2 Activate

# Technical Stuff
* Enter bootloader using Layer 1 ESC
* Reboot keyboard using Layer 1 Grave/Backtick
* Clear EEPROM using Layer 1 Tab
